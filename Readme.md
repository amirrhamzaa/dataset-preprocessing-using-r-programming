Dataset Preprocessing Using R Programming

Project Overview

This repository contains our Introduction to Data Science (IDS) Midterm Project for Fall 2026–2027. The project focuses on dataset exploration, data cleaning, preprocessing, transformation, and statistical analysis using R Programming.

We used the Stroke Prediction Dataset to apply different data preprocessing techniques and gain practical experience in working with real-world data.

Dataset Information

- Dataset Name: Stroke Prediction Dataset
- Total Records: 5,110
- Total Attributes: 12
- Target Variable: `stroke`
- Programming Language: R
- Tools Used: R and RStudio

The dataset contains patient information, including age, gender, hypertension, heart disease, marital status, work type, residence type, average glucose level, BMI, and smoking status.

Tasks Performed

The project covers the following tasks:

1. Dataset Loading and Exploration
2. Missing Value Detection and Handling
3. Outlier Detection and Handling Using IQR
4. Categorical and Numerical Data Conversion
5. Min-Max Normalization
6. Duplicate Value Detection and Removal
7. Data Filtering
8. Invalid Data Detection and Removal
9. Feature Creation
10. Class Balancing Using Under-sampling and Over-sampling
11. Training and Testing Data Splitting
12. Mean and Median Imputation Comparison
13. Descriptive Statistical Analysis
14. Group-wise Statistical Comparison
15. Variability Analysis

How to Run

1. Clone this repository.
2. Open `Group_04_Stroke_Prediction.R` in RStudio.
3. Make sure the dataset CSV file is available.
4. Update the dataset file path in the R script according to your local directory.
5. Run the script to execute the project tasks.

Project Objective

The objective of this project is to develop practical skills in data exploration, data cleaning, missing value handling, outlier treatment, data transformation, normalization, and statistical analysis using R Programming.
